# Python 3.13: Learn From Zero to Pro (2026)

Python 3.13: Learn From Zero to Pro (2026) is a comprehensive collection of source code, practical exercises, tasks, and mini-projects developed throughout the course **"Curso de Python 3.13: Aprende Desde Cero a Pro 2026"** completed on **Udemy**, totaling **7 hours** of instruction.

This repository provides a structured learning path through the Python programming language, progressing from fundamental syntax and control flow to data structures, modular programming, functions, and Object-Oriented Programming (OOP).

Python is a high-level, object-oriented language that is easy to learn, read, and write. It enables developers to start thinking like programmers from day one and build everything from simple automation scripts to complex software architectures.

## Key Learning Outcomes

* **Syntax & Fundamentals:** Handling variables, data types, operators, and conditional logic (`if-elif-else`).
* **Advanced Control Flow:** Structural pattern matching (`match-case` in Python 3.10+), loops (`for` / `while`), string manipulation, and tuple handling.
* **Data Structures & Integration:** Working fluently with lists, record-oriented dictionaries, and custom external modules.
* **Functions & Modularity:** Writing reusable code, managing arguments, and controlling parameters.
* **Object-Oriented Programming (OOP):** Class design, object instantiation, encapsulation, inheritance, and polymorphism via abstract classes.

## Projects Included

---

### `Part 1: Fundamentals & Control Flow/`

**Objective:**
Establish core Python syntax, cover terminal input/output, handle dynamic type casting, and build basic conditional logic.

**Concepts Applied:**

* Terminal I/O (`print()`, `input()`)
* Data type inspection and explicit casting (`int`, `float`, `str`, `type()`)
* Module imports and constant declarations (`config.py`)
* Arithmetic and relational operator evaluations
* Multi-branch conditional logic (`if`, `elif`, `else`)

**Description:**
Includes fundamental scripts for user interactions, arithmetic expressions, age group categorization, and an academic grading evaluator (`grade_evaluator.py`).

---

### `Part 2: Advanced Control Flow, Iteration & Sequences/`

**Objective:**
Master pattern matching, definite and indefinite loop iterations, string transformations, and immutable sequence processing.

**Concepts Applied:**

* Structural pattern matching (`match-case` with `if` guards)
* Definite (`for`) and indefinite (`while`) loops
* Sentinel loop termination and dynamic accumulators
* String methods (`len()`, `split()`, `replace()`, `upper()`, `lower()`)
* Tuple sequence handling and unpacking

**Description:**
Features numerical range evaluators, sequence average calculators, countdown timers, continuous prompt accumulators, text search utilities, and immutable record filtering.

---

### `Part 3: Data Structures, Modular Programming & Functions/`

**Objective:**
Manage mutable and mapping collections (lists and dictionaries), write reusable functions with explicit return values, and separate concern using external modules.

**Concepts Applied:**

* List operations (`append()`, `del`, `sum()`) and indexing
* Key-value data modeling and nested lookup schemas
* Function declarations (`def`), argument passing, and returns (`return`)
* Module design and cross-file imports (`import`)

**Description:**
Covers list transformations, interactive contact profile forms, command-line calculators powered by custom functions, and external mathematical utility modules (`miprimermodulo.py`).

---

### `Part 4: Object-Oriented Programming (OOP)/`

**Objective:**
Model real-world entities using Object-Oriented paradigms in Python.

**Concepts Applied:**

* Class definitions, constructors (`__init__`), instance attributes, and methods (`self`)
* Class inheritance (`ChildClass(ParentClass)`)
* Abstract Base Classes (`ABC`, `@abstractmethod`) and Polymorphism
* Attribute encapsulation and private name mangling (`__attribute`)

# Python Fundamentals & Control Flow

Python Fundamentals & Control Flow is a comprehensive collection of programs developed to strengthen foundational knowledge of the Python programming language. Each project addresses a specific programming concept, including input/output operations, variables, constants, type casting, arithmetic and relational operators, and conditional decision-making structures.

With a problem-solving oriented approach, this repository provides a centralized reference for exploring the building blocks of Python development.
It demonstrates how core principles can be applied to implement clear and structured solutions, while serving as both a learning resource and a portfolio showcase.

## Projects Included

---

### `1.Print/main.py`

**Objective:**
Learn how to print messages to the console and handle basic string outputs in Python.

**Concepts Applied:**

* Console output (`print()`)
* String literal syntax

**Description:**
Runs basic print operations to display simple text and initial program messages on the terminal screen.

**Output:**

Standard text strings printed directly to the console.

**Potential Applications:**

* Basic debugging and terminal user messaging.

---

### `2.Comentarios y Declaración/main.py`

**Objective:**
Understand how to document code and structure basic statements in Python.

**Concepts Applied:**

* Single-line and multi-line comments
* Code readability

**Description:**
Demonstrates the use of `#` comments to annotate code execution flow without affecting script execution.

**Output:**

Execution of the underlying code statements while ignoring comments.

**Potential Applications:**

* Code documentation and temporary execution suppression during testing.

---

### `3.Variables, Constantes y Literales/`

**Objective:**
Learn variable management and how to handle modular constants across multiple source files.

**Concepts Applied:**

* Variable assignment
* Constants management (`config.py`)
* Module imports (`import`)

**Description:**
Defines static configuration parameters (such as `PI`) inside `config.py` and imports them into `main.py` to preserve separation of concerns.

**Output:**

Access and display of imported constant values.

**Potential Applications:**

* Managing application settings, environmental parameters, and static configuration files.

---

### `4.Tipos de Datos/main.py`

**Objective:**
Capture dynamic user input and handle data type inspection and casting.

**Concepts Applied:**

* User input handling (`input()`)
* Explicit type conversion (`int()`, `float()`)
* Type inspection (`type()`)

**Description:**
Prompts the user for a text string, an integer, and a decimal number, converts each input to its appropriate type, and verifies the final data types using `type()`.

**Output:**

Outputs each entered value alongside its evaluated Python data type (`str`, `int`, `float`).

**Potential Applications:**

* Validating and transforming user data from CLI forms or external user interfaces.

---

### `5.Operadores/main.py`

**Objective:**
Master arithmetic computation and comparison operations in Python.

**Concepts Applied:**

* Arithmetic operators (`+`, `-`, `*`, `/`, `//`, `**`)
* Comparison operators (`>`, `<`, `==`, `!=`, `>=`, `<=`)

**Description:**
Performs various mathematical calculations between numerical operands and evaluates comparison expressions to return boolean values (`True`/`False`).

**Output:**

Console display of numerical calculation results and boolean comparison outcomes.

**Potential Applications:**

* Core computational logic, mathematical modeling, and evaluation of programmatic conditions.

---

### `6.Sentencia if/`

**Objective:**
Implement decision-making structures to direct execution flow based on dynamic rules.

**Concepts Applied:**

* Multi-branch conditional logic (`if`, `elif`, `else`)
* Comparison and logical evaluation

**Description:**
Includes two scripts: `example.py`, which evaluates basic numerical ranges, and `age_classifier.py`, which categorizes user input into age groups (Child, Teenager, Adult, Senior) while handling invalid negative numbers.

**Output:**

Targeted text responses based on the provided numerical evaluations.

**Potential Applications:**

* User classification, form validation, and conditional business logic rules.

---

### `7. Tarea final/grade_evaluator.py`

**Objective:**
Build a complete student grading evaluator combining user input, type casting, and range checking.

**Concepts Applied:**

* Nested and sequential conditionals
* Range comparisons with combined operators (`and`)
* Floating-point to integer conversions

**Description:**
Prompts for a student's grade, converts it to a numerical format, and outputs an academic assessment ranging from outstanding performance to failing status.

**Output:**

A personalized feedback message indicating academic performance.

**Potential Applications:**

* Automated evaluation engines, scoring systems, and grading platforms.
